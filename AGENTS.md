# Rules 

## Language

- Default Language is English.
- Yoruba, always rendered Yorùbá, is the alternative language. 
- Add Yoruba translations `i18n/en-yo.json` (code in `i18n/index.js`)

## Design & Development

- In HTML, use `svg` and `path` to build custom icons.
